# AI v8: 2026-10-14 자료 반영

새 자료는 2026-10-13 23:36 ~ 2026-10-14 19:01 KST의 고유 글 3,633개, 공개 댓글 14,699개입니다.
JSONL과 analysis JSON의 글 목록은 완전히 같습니다. TXT도 같은 글을 표현한 자료이므로 세 번 합산하지 않습니다.
이전 10,000개 자료와 URL이 겹치지 않습니다.

전체 글을 프로그램으로 검사하고 드래프트·평가·선수 역할과 관련된 731개 검토 후보를 추렸습니다.
새 정책에 반영한 것은 본문·댓글 맥락을 검토한 16개 신호입니다. 모든 댓글을 실력 점수로 환산한 것은 아닙니다.
게시물에 포함된 이미지나 영상의 실제 내용은 이번 자료의 텍스트만으로 확인하지 않았습니다.

## 반영한 변화

- 큐베: 최근 수행과 사이드 영향력 평가를 반영합니다. 엘리와 하위 딜러들보다 과도하게 뒤로 밀리지 않도록 기존 기량 차이를 유지합니다.
- 둥그레: 큐베·유니를 원하는 팀 구성 선호를 반영합니다. 이것이 유니의 오더 기량이 남봉보다 높다는 뜻은 아닙니다.
- 푸린: 디디디용 검토, 마뫄의 메인딜 역할 비선호, 마지막 양아지 재검토를 각각 반영합니다. 확정 선발이나 선수 전체 기량 하락으로 취급하지 않습니다.
- 울프: 양아지·남봉·마뫄 중 두 명의 조합을 비교합니다. 힐러 둘을 먼저 뽑고 나중에 약한 딜러 둘을 받는 손실을 더 크게 계산합니다. 아직 확인되지 않은 유찰 딜러의 성장을 가정하지 않습니다.
- 삐부: 캐리 딜러를 받치는 역할과 유니의 본대힐 파트너 선호를 반영합니다. 언급량만으로 모든 힐러보다 강하게 만들지 않습니다.
- 인섹·정령왕: 관측된 수행을 작게 반영하고 콜, 기량, 코칭 참여를 구분합니다.

숫자는 구현을 위한 잠정 판단이며 실제 승률, 경기 기록, 울프가 제시한 등수가 아닙니다.
울프의 기존 매물 평가와 선수의 기본 프로필을 유지하고, 새 커뮤니티 근거를 최신 시각 기준으로 보정합니다.
같은 기량과 신뢰도의 근거는 12시간마다 영향력이 절반으로 줄어듭니다.
같은 사건을 반복한 글은 event 키로 묶어 한 번만 계산합니다.

이번 기본 시뮬레이션에서는 처음에 뱅 → 김뿡 → 큐베 → 디디디용이 선발되고,
울프는 양아지·마뫄, 푸린은 남봉, 둥그레는 유니를 선택합니다.
이는 현재 평가로 계산한 한 가지 결과이며, 사람이 다른 선수를 뽑으면 남은 조합을 다시 계산합니다.
울프가 반드시 딜딜이나 힐힐을 선택하도록 강제하지 않습니다.

## 실행과 검증

선발 이유는 표시하지 않습니다. AI는 외부 API 없이 배포된 JavaScript 정책으로 동작합니다.
모델 재학습이나 실시간 커뮤니티 학습을 수행하는 기능은 아닙니다.
새 자료를 반영하려면 근거와 정책을 갱신해 다시 배포해야 합니다.

조합 계산은 서로 다른 상대 선발 성향 세 가지에서 최종 팀을 예상합니다.
연속 두 턴에서는 두 선수를 함께 비교하고, 픽을 확정할 때마다 현재 방 상태로 다시 판단합니다.
20명 중복 없이 각 팀 딜러 2명·힐러 2명을 유지합니다.
근거의 시간 가중치는 배포 버전당 한 번 계산해 반복 계산을 줄였습니다.

Cloudflare에서는 방별 Alarm으로 AI 선발을 실행합니다.
일부러 몇 초씩 기다리는 지연은 없습니다. 빈 팀은 즉시 자동 선발을 예약하고,
연결이 끊긴 기존 팀장은 30초의 복귀 시간을 줍니다.
일반 방의 접속 중인 팀장에게는 시간 제한이 없습니다. 랜덤매칭은 30초입니다.
