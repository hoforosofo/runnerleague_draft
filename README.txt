러너리그 드래프트 전체 수정본

- 드래프트 순서 변경 시 완료된 픽과 팀 배정 유지
- 각 라운드의 빈 차례만 새 순서로 재배정 (홀수 라운드 정방향, 짝수 라운드 역방향)
- 라운드마다 각 팀이 한 번씩 선발
- 돌격 순서 → 드래프트 순서
- 최종 결과는 팀별 가로 한 줄, 실제 선발 순서 및 전체 픽 번호 표시
- 코치를 별도 배정하면 별도 배정으로 표시

model.mjs, style.css, 모든 이미지와 폰트를 포함한 전체 프로젝트입니다.
기존처럼 웹 서버에서 index.html을 열어 사용하세요.

검증: 실제 선수 데이터로 코치 포함/제외, 반복 순서 변경, 라운드별 중복 방지, 취소/재선발, 최종 결과 생성 및 모든 선수 이미지 경로 확인.
브라우저 미리보기의 로컬 연결이 실패하여 시각적 화면 검증은 완료하지 못했습니다.
